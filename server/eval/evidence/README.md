# 합성 관찰 문장의 근거 검색 점검

아래 두 시험은 실제 영상 분석을 마친 뒤, 교사가 확인할 문장에서 맞는 자료를 고르는 단계를 측정한다. 입력은 직접 작성한 한국어 문장과 가상 월령이다. 오답을 점검해 검색 코드와 프롬프트를 수정했으므로 최종 성적은 회귀 시험 결과로 읽는다.

| 대상 | 상황별 추천 | 보류해야 할 상황에서 보류 |
| --- | --- | --- |
| 기존 자료 7개, 문장 24개 | 6/14 | 10/10 |
| 확장 자료 51개, 같은 문장 24개 | 14/14 | 10/10 |
| 다른 표현 9개, 첫 실행 | 4/5 | 3/4 |
| 다른 표현 9개, 수정 후 재실행 | 5/5 | 4/4 |

2026-11-20에 로컬 Ollama의 `qwen3.5:4b`로 측정했다. 실제 아동 영상에서 행동을 인식하는 성능은 별도로 평가해야 한다. 모델 설치 후 AI 저장소 루트에서 아래와 같이 현재 자료로 재실행한다. 각 실행은 기대한 행동 유형과 실제 선택한 자료를 JSON으로 출력한다.

```sh
node server/eval/evidence/run.mjs
node server/eval/evidence/run.mjs --fresh
```
