| --- | --- |

[국내 자료 목록](korean/sources.json)과 [해외 자료 목록](international/sources.json)에 원문 주소, 수집일, 이용 조건, 보관 범위와 SHA-256을 기록했습니다. 한국어 대응 문장은 지침을 관찰 상황에 적용한 예시입니다.

## 검색과 검토

SQLite의 `source_document`는 수집한 원문 텍스트를 보관합니다. `passage_provenance`는 각 신규 근거를 원문 구절에 연결합니다. FTS5 색인에서 관찰 문장의 행동 단어를 검색하고, 아이의 월령과 실제 행동 단서를 적용합니다. 로컬 모델은 후보의 원문 구절, 요약, 행동 제안을 대조해 최대 두 개를 고릅니다. 교사가 문장을 수정하면 다시 검색하며, 보호자에게는 교사가 선택해 전달한 결과가 표시됩니다.

## 오프라인 재구성

[합성 문장 비교 결과와 실행 방법](../eval/evidence/README.md)에는 자료 확장 전후의 추천 수와 보류 수가 정리되어 있습니다.

AI 저장소 루트에서 다음 명령을 실행합니다.

```sh
node server/evidence/build.mjs
```

빌드는 보관 파일의 해시와 각 신규 근거의 원문 구절을 검증한 뒤 SQLite 파일을 생성합니다. `korean/verify_downloads.py`는 국내 자료를 발행처에서 다시 받아 대조하고, `international/download_dfe.py`는 영국 교육부 자료에서 해당 절을 추출합니다. 자료의 내용이나 추천을 변경해 배포할 때는 새 버전을 부여합니다. 전달을 마친 기록에는 당시 근거 버전과 출처가 함께 저장됩니다.
