# 영상 관찰 기록의 행동·역할 비교

2026년 11월 20일, 연구에서 공개한 영상 67편의 같은 72구간을 두 버전에서 분석했다. 각 구간에서는 서비스가 사용하는 방식으로 무음 장면 사진 6장을 골랐다. 아이가 혼자 있는 구간에서 공동놀이를 잘못 기록하는지, 대화 표현을 검토하는 과정에서 실제 행동까지 사라지는지 살폈다.

| 같은 구간에서 새로 생성한 기록 | 이전 운영판 | 개선판 |
| --- | ---: | ---: |
| 아이만 보일 때 공동놀이로 잘못 기록 | 1/16 | 0/16 |
| 근거 없는 공동놀이가 있는 기록 | 6/72 | 4/72 |
| 아이와 어른의 역할을 명백히 잘못 기록 | 7/72 | 5/72 |
| 근거 없는 대화가 있는 기록 | 0/72 | 0/72 |
| 세부 판독 표본에서 주요 행동을 포착 | 20/29 | 23/29 |
| 걷는 주체를 아이로 기록 | 16/34 | 19/34 |

같은 자료로 새 초안을 만들면 초안 자체도 달라진다. 검토 단계의 영향만 보기 위해 이전 운영판의 초안을 고정한 비교도 수행했다. 이 조건에서 근거 없는 공동놀이는 6/72에서 4/72로 줄었고 주요 행동 포착은 전후 모두 20/29였다. 보행을 아이에게 귀속한 기록은 16/34에서 15/34로 줄었다. 역할을 확신하기 어려울 때 표현을 ‘사람’으로 바꾸면서 아이의 행동이라는 정보도 빠질 수 있었다.

기준 운영판은 `obs-v5.3-limited`였다. 개선판은 시각 모델부터 다시 실행해 채점한 뒤 마지막 문장 보정을 추가했다. 최종 코드 `obs-v6.3.1-preserved`에서 같은 모델 응답을 재생했을 때 표의 점수는 그대로였다. PC에서 한 건씩 새로 생성한 응답의 중앙값은 2.16초에서 3.79초, 95백분위수는 2.39초에서 4.84초로 늘었다. 시간은 휴대폰의 영상 처리와 네트워크 구간을 제외하고 측정했다.

자료는 Dryad 공개 보행 자료, Cavallo 등 연구진의 물건 잡기 과제, 미국언어청각협회(ASHA)와 학술 출판사의 언어 발달 관련 연구 보충자료에서 가져왔다. 한 아동의 반복 촬영과 한 영상에서 나눈 구간이 포함된다. 일부 장면은 개선 방향을 정할 때도 사용했으므로 이 수치를 새로운 아동 전체에 일반화할 수 없다. 추천 자료를 검색하는 단계는 [별도 합성 문장 평가](../../server/eval/evidence/README.md)에서 다뤘다.
