# 5초 음원에서 울음 소리 구분하기

함께자람의 휴대폰 분석기는 높고 큰 소리가 이어진 구간을 울음 후보로 센다. 이 실험은 사람이 **울음 소리가 들어 있다**고 분류한 음원을 다른 생활음과 구분하는 학습 모델을 만든다. 5초 녹음 단위이며 울음의 시작·끝, 횟수, 감정, 발달 상태 라벨은 없다.

## 받은 데이터

Karol J. Piczak의 ESC-10은 CC BY 3.0으로 배포된다. 배포자가 제공하는 개별 파일 크레디트까지 확인하고 원음이 CC0 또는 CC BY인 398개 WAV(175,535,512바이트)만 받았다. 아기 울음 40개와 개 짖기, 파도, 닭 울음 등 9종 생활음 358개다. 원음 조건이 CC Sampling+인 닭 울음 두 건은 제외했다. 데이터 버전은 `33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6`이다. [배포자 및 논문 정보](https://github.com/karolpiczak/ESC-50/tree/33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6) · [데이터셋 조건과 음원별 저작자·출처](https://github.com/karolpiczak/ESC-50/blob/33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6/LICENSE) · [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)

`python fetch_esc10.py`를 실행하면 원음과 `esc10/manifest.csv`가 로컬에 생성된다. 목록에는 WAV별 원작자·크레디트, 다운로드 주소, SHA-256, Git blob 해시, 원본 녹음 ID와 분할 번호가 있다. 특징을 만들 때 16 kHz 모노로 바꿨다.

## 학습과 검증

배포자가 지정한 1~3번 폴드 238개로 학습하고, 4번 폴드 80개로 판정 문턱을 정했다. 5번 폴드 80개는 마지막 비교에만 썼다. 서로 다른 폴드에 같은 원본 녹음 ID가 없는지 검사했다. 모델은 100~6,000 Hz의 24개 로그 멜 대역에서 평균·표준편차·시간 변화를 뽑고, 클래스 가중치를 준 로지스틱 회귀로 학습한다. 결과는 `cry_model.json`이다. 기존 규칙도 같은 16 kHz PCM으로 실제 함께자람 `analyzeAudio` 함수를 호출했고 울음 구간이 1회 이상이면 양성으로 셌다.

| 5번 폴드에서 센 값 | 기존 규칙 | 학습 모델 |
|---|---:|---:|
| 울음 소리를 검출한 수 (8개 중) | 0 | 4 |
| 생활음을 울음으로 잘못 분류한 수 (72개 중) | 17 | 3 |
| 정밀도 / 재현율 | 0 / 0 | 0.57 / 0.50 |
| F1 | 0 | 0.53 |

이 결과는 57개 원본 녹음에서 나온 80개 시험 클립의 결과다. 문턱을 정한 4번 폴드에서는 울음 8개 중 7개를 찾아 폴드 간 편차도 있었다. 일반적인 아이 말소리·웃음이나 다양한 연령대의 가정 촬영 영상에서 같은 성능을 전제할 수 없다. 원 저자도 녹음 전처리 차이로 생기는 데이터 편향을 명시한다. 이 모델은 별도 실험 파일로 제공하며, 폰에서 계산하는 운영 지표에는 적용하지 않았다.

## 재현

이 디렉터리에서 `python fetch_esc10.py`로 파일을 검증해 받고 `uv run train.py`로 학습 및 비교를 재현한다. 기존 규칙 실행에는 Node 24가 필요하다. `results.json`에 갈래별 오탐과 집계가, `predictions.csv`에 파일별 결과가 있다. 5초짜리 WAV 한 파일에 모델을 적용하려면 `uv run --python 3.12 --with numpy==2.2.6 --with scipy==1.15.3 python cry_clip.py 파일.wav`를 실행한다.
